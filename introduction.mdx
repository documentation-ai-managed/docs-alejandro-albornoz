## Overview

Welcome to Alejandro Albornoz's documentation space. You use this platform to organize, manage, and share all your project documentation in one centralized location. It supports Markdown-based pages, version history, and collaboration features, making it ideal for developers, teams, and personal projects. Start creating structured docs today to streamline your workflow.

<Callout kind="info">
  This space uses brand color `#3B82F6` for consistent theming across all documentation.
</Callout>

## Quick Start

Get up and running in minutes with these steps.

<Steps>
  <Step title="Create Your First Space" icon="plus">
    Navigate to the dashboard and click `New Space`. Enter a name like `My Project Docs` and select your brand color `#3B82F6`.
  </Step>
  <Step title="Add a Page" icon="file-text">
    Inside your space, create a new MDX page. Use the editor to write content with components like `<Callout>` and `<Steps>`.
  </Step>
  <Step title="Publish and Share" icon="share-2">
    Preview your docs, then publish. Share the public URL or embed it in your app using the provided snippet.
  </Step>
</Steps>

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Embed docs in your React app
  import { DocsEmbed } from '@alejandro-albornoz/docs';

  function App() {
    return (
      <DocsEmbed spaceId="your-space-id" height="600px" />
    );
  }
  ```
  ```python
  # Embed docs in your Streamlit app
  import streamlit.components.v1 as components

  components.html(
      """
      <iframe src="https://docs.alejandro-albornoz.com/your-space" height="600"></iframe>
      """,
      height=600
  )
  ```
</CodeGroup>
