## Recent Updates

Stay informed about the latest releases for Alejandro Albornoz's documentation platform. You receive new features, performance improvements, and critical bug fixes to enhance your documentation workflow.

<Update label="2024-10-15" description="v1.2.0" tags={["feature", "bugfix"]}>

## New Features

- Added real-time collaboration editing, allowing multiple users to edit documents simultaneously.
- Introduced custom branding options, including support for your brand color `#3B82F6`.
- New search indexing for faster document discovery across your entire space.

## Improvements

- Enhanced editor performance by `>30%` for large documents.
- Improved mobile responsiveness for better viewing on tablets and phones.

## Bug Fixes

- Fixed sync issues when switching between tabs during edits.
- Resolved export errors for documents with embedded images.

</Update>

<Update label="2024-09-20" description="v1.1.0" tags={["feature", "improvement"]}>

## New Features

- Integrated version history with diff viewer to compare changes over time.
- Added template gallery for quick-start documentation setups.

## Improvements

- Optimized image uploads with automatic resizing and compression.
- Better keyboard shortcuts, including `Ctrl+K` for command palette.

## Bug Fixes

- Corrected table rendering glitches in preview mode.
- Fixed link validation for external URLs.

</Update>

<Update label="2024-08-10" description="v1.0.0" tags={["breaking", "feature"]}>

## Initial Release

- Core documentation editor with rich text and markdown support.
- Space organization for projects and teams.
- Basic export to PDF and HTML.

## Breaking Changes

- Updated API endpoints to use `https://api.example.com/v1/` prefix.

</Update>

## Upgrade Instructions

Follow these steps to ensure you run the latest version smoothly.

<Steps>
  <Step title="Check Current Version" icon="check-circle">

    Run the version check command:

    ````bash
    alejandro-albornoz --version
    ````

  </Step>
  <Step title="Update Package" icon="download">

    <Tabs>
      <Tab title="npm" icon="package">
        ````bash
        npm update alejandro-albornoz
        ````
      </Tab>
      <Tab title="Yarn" icon="package">
        ````bash
        yarn upgrade alejandro-albornoz
        ````
      </Tab>
    </Tabs>

  </Step>
  <Step title="Restart Server" icon="refresh-cw">
    Restart your local development server to apply changes.
  </Step>
</Steps>
